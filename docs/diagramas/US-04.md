# US-04: Árvore de Diálogo dos Dreamers (Alucinações)

[← Voltar para a lista de diagramas](./README.md)

### Cartão
> Como jogador, eu quero confrontar o entrevistado com perguntas sobre memórias pessoais não documentadas, para provocar alucinações (geração de dados falsos com confiança) em IAs do tipo "Dreamer".

### Conversa
* Se perguntado sobre dados ausentes na Ficha de Inspeção, o Dreamer inventa histórias detalhadas e fluidas com alta confiança (alucinações). Se for humano, nega a existência do evento.

### Confirmação
* 3 árvores de diálogo (2 humanas, 1 Dreamer); Dreamer gera versão falsa inédita ou divergente entre dias; humanos negam a existência do evento.
