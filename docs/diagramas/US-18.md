# US-18: Escanear Anomalias Físicas no Interrogatório

[← Voltar para a lista de diagramas](./README.md)

### Cartão
> Como jogador, Eu quero tirar capturas fotográficas de regiões anatômicas específicas do entrevistado (olhos, mãos, textura cutânea) para submetê-las ao scanner de integridade biológica, Para que eu possa identificar artefatos visuais de rendição sintética, falhas de iluminação ou ausência de micro-respostas orgânicas.

### Conversa
* O jogador ativa o Scanner apontando para regiões anatômicas (Olhos, Mãos, Pescoço).
* A ação consome 1 Bateria/Token. O resultado é processado pela tipologia:
  * Talker: Revela artefatos severos de Deepfake.
  * Dyad / Dreamer: Imagem impecável, exigindo outras ferramentas.
  * Humano: Revela imperfeições biológicas (fazer isso repetidas vezes esgota a paciência).
* A imagem analisada com caixas de alerta é anexada na Ficha de Inspeção.

### Confirmação
- [ ] O jogo destaca as zonas de captura com pontilhados.
- [ ] O sistema gera uma caixa amarela de anomalia visual ao escanear Talkers.
- [ ] O sistema retorna padrão anatômico dentro dos limites para Dreamers e Dyads.
- [ ] A miniatura da foto aparece no campo de anexos da Ficha.
