# US-08: Botão de Ajuda (Minigame Lógico)

[← Voltar para a lista de diagramas](./README.md)

### Cartão
> Como inspetor, eu quero um botão de ajuda caso ainda não tenha noção de meu veredito.

### Conversa
* Botão de dica com 2 usos por dia. Apresenta proposição lógica para classificar em Tautologia, Contradição ou Contingência. Acerto libera diálogo investigativo poderoso sem penalidade; erro encerra a ajuda na conversa atual.

### Confirmação
* Botão clicável na tela de diálogo; proposição lógica com 3 opções; diálogo privilegiado em caso de acerto; bloqueio do botão na conversa em caso de erro.
