# US-12: Gatilho para Finais e Consequências Corporativas

[← Voltar para a lista de diagramas](./README.md)

### Cartão
> Como jogador, eu quero que o jogo termine com as consequências dos meus atos corporativos, baseados no número de sintéticos que deixei escapar, para sentir que minha eficiência foi avaliada. OU achando o final secreto no gabinete do CEO, para descobrir que é um Sintético.

### Conversa
* Lógica condicional (IAs aprovadas <= X -> Final A; > X -> Final B) com cutscenes textuais em Raylib. Rota do Final Secreto via elemento interativo no gabinete do CEO.

### Confirmação
* Avaliação do score oculto no último dia; exibição de relatório com Falsos Positivos/Negativos e Scoreboard; cutscenes do Final A, Final B ou Final Secreto de auto-descoberta.
